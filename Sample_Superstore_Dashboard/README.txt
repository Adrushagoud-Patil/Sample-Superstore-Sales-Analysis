# Sales Performance Dashboard – Power BI

## Project Overview
This project presents an interactive Sales Performance Dashboard built using Microsoft Power BI and the Sample Superstore dataset.

The dashboard helps analyze sales, profit, orders, quantity, product performance, and regional sales trends.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization

## Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Orders
- Total Quantity

## Dashboard Visualizations
- Monthly Sales Trend
- Sales by Region
- Top 5 Products by Sales
- Sales by State
- Profit by Category

## Interactive Filters
- Order Date
- Region
- Category
- Customer Segment

## Dataset
Sample Superstore dataset containing sales transactions, customer details, products, regions, and order information.

## Project Files
- `Dataset/` – Original dataset
- `Dashboard/` – Interactive Power BI dashboard (.pbix)
- `Screenshots/` – Dashboard preview images
